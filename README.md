# Lamoda Parser 🛍️

Python скрипт для получения данных о товарах с сайта Lamoda.ru

## 🚀 Установка

1. Создайте виртуальное окружение:
```bash
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## 📖 Использование

### Быстрый старт

Запустите рабочий скрипт:
```bash
python lamoda_final_parser.py
```

Результат:
- Выводит список товаров в консоль
- Сохраняет все данные в `lamoda_products_working.json`

### Пример вывода

```
================================================================================
НАЙДЕНО ТОВАРОВ: 66
================================================================================

1. Ветровка
   Бренд: adidas Originals
   Артикул: RTLAER004001
--------------------------------------------------------------------------------
2. Олимпийка
   Бренд: adidas Originals
   Артикул: RTLAER003901
--------------------------------------------------------------------------------
...
```

## 📁 Доступные скрипты

### 1. **lamoda_final_parser.py** ⭐ (РЕКОМЕНДУЕТСЯ)
Основной рабочий парсер. Извлекает данные из встроенных JavaScript данных страницы.

```bash
python lamoda_final_parser.py
```

**Преимущества:**
- ✅ Работает без браузера
- ✅ Быстрый
- ✅ Извлекает название, бренд, артикул товаров

### 2. **lamoda_parser.py**
Базовый парсер с BeautifulSoup.

```bash
python lamoda_parser.py
```

### 3. **lamoda_advanced_parser.py**
Продвинутый парсер с множественными методами извлечения.

```bash
python lamoda_advanced_parser.py
```

### 4. **lamoda_parser_selenium.py**
Парсер с Selenium (требует Chrome/ChromeDriver).

```bash
python lamoda_parser_selenium.py
```

⚠️ Требует установки Chrome и ChromeDriver.

## 📊 Структура данных

Каждый товар содержит:

```json
{
  "name": "Ветровка",
  "brand": "adidas Originals",
  "sku": "RTLAER004001",
  "price": "12999",
  "currency": "RUB",
  "url": "https://www.lamoda.ru/p/RTLAER004001/",
  "image": "https://a.lmcdn.ru/...",
  "category": "Одежда"
}
```

## 🛠️ Изменение URL

Чтобы парсить другую категорию, измените URL в файле:

```python
# В lamoda_final_parser.py
url = "https://www.lamoda.ru/ВАША-КАТЕГОРИЯ/"
```

Примеры категорий:
- Adidas Originals: `/b/1163/brand-adidasoriginals/?sort=new`
- Nike: `/b/8164/brand-nike/`
- Женская одежда: `/c/355/clothes-zhenskaya-odezhda/`

## ⚠️ Важные замечания

1. **Защита от ботов**: Lamoda использует защиту от автоматизированного доступа. Скрипт может перестать работать.

2. **Юридические аспекты**: Убедитесь, что ваше использование соответствует условиям использования сайта.

3. **Ограничение запросов**: Не делайте слишком много запросов, чтобы не перегружать сервер.

4. **Обновления сайта**: При изменении структуры сайта скрипт может требовать обновления.
